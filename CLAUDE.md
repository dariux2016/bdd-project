# bdd-project

## Agent skills

### Issue tracker

Issue e spec vivono nelle GitHub Issues di `dariux2016/bdd-project` (CLI `gh`). See `docs/agents/issue-tracker.md`.

When a ticket (GitHub issue #N) is done, end the final commit message with `Closes #N` and `git push origin main`: the push closes the issue.

### Triage labels

Le cinque label canoniche di default, senza rinomine. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` e `docs/adr/` alla radice del repository. See `docs/agents/domain.md`.
